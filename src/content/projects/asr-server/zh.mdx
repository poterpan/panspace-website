## 背景與問題

開完會想讓 LLM 幫忙整理重點，前提是要有一份分得出誰說了什麼的逐字稿。雲端服務要把錄音上傳給第三方，中文輸出也常是簡體或對岸用語。

## 我的角色

獨立開發：轉錄管線、API、網頁介面與部署說明。

## 做法與技術決策

以 FunASR 串起語音活動偵測、語音辨識、標點還原與講者分離四個模型，模型只載入 GPU 一次，所有工作共用。辨識結果再用 OpenCC 轉成台灣繁體用語。

輸出格式為 LLM 設計：同一位講者連續的發言會合併，時間只保留粗略的分秒標記，比逐句列出的 Markdown 少掉大約八成的格式 token。服務是 FastAPI，附一個單檔、免建置的網頁介面，可選擇用 Bearer token 或 Cloudflare Access 保護。

## 成果

在單張 RTX 3090 上完整跑通，原始碼開源在 GitHub。

## 學到什麼

逐字稿的使用者其實是 LLM，所以輸出格式值得像 API 一樣認真設計：留下模型需要的資訊，拿掉只會浪費 token 的部分。
