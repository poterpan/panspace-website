## 背景與問題

北科的課表、成績、校園公告和選課分散在好幾個校務系統裡，每個都要各自登入，手機上也不好用。想知道「下一節在哪間教室」，往往要先開瀏覽器、登入、再找到正確的頁面。

我想做的是一個每天打開就有答案的 App：登入一次，課表、成績和公告都在手邊，主畫面的小工具直接顯示下一節課。

## 我的角色

一個人負責整個產品：產品規劃、iOS App、官網、排課網站、資料管線、後端服務、部署與監控。

## 做法與技術決策

**App 本體**用 SwiftUI 開發，SwiftData 存本機資料，課表離線也能看。登入走學校的 SSO 流程，密碼只存在 iOS Keychain，不經過我的伺服器。WidgetKit 小工具透過 App Group 和主程式共用資料，依目前時間判斷要顯示「進行中」還是「下一節」。

**排課網站** [course.ntutbox.com](https://course.ntutbox.com) 只負責規劃：不登入，也不代替學生操作學校系統。Python 爬蟲在 GitHub Actions 上排程，每天更新課程與人數、每週更新課綱與教室課表，產出的 JSON 發佈到 Cloudflare R2。網頁是 Next.js 靜態輸出，全文搜尋在前端完成。排好的課表透過 Universal Link 帶進 App，送出前一律由學生本人確認。這部分[開源在 GitHub](https://github.com/poterpan/ntutbox-course)。

**其他服務**都跑在 Cloudflare 上：[QR Code 簽到系統](https://github.com/poterpan/ntutbox-checkin)（Next.js、D1、KV，QR Code 每 30 秒輪換，搭配一次性 nonce 防重放）、[節次範本 API](https://github.com/poterpan/ntutbox-template-api)（讓其他學校的課表也能匯入），以及監控校務系統的服務狀態頁。App 出問題時，可以先看狀態頁判斷是不是學校系統掛了。
