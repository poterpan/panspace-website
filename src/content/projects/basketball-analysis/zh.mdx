## 背景與問題

教練看投籃影片，要找的是幾個關鍵瞬間：開始蓄力、蓄力到最深、出手。這些時間點和當下的關節角度，決定了動作好不好。人工逐格找既慢又看人，客戶希望學員自己上傳影片，就能拿到一份一致的分析報告。

## 我的角色

技術負責人：標註工具、模型訓練、推論服務、雲端架構與報告網頁都由我設計與實作，並和客戶對齊規格、驗收與交付。

## 做法與技術決策

**先做標註工具。** 我做了一個網頁版的影格標註工具，直接從影片容器讀出幀率與總幀數，用快捷鍵逐格標出三個關鍵時間點，也能把模型的預測一鍵收為標註，讓資料和模型可以一起迭代。

**模型選擇看的是上線，不只是分數。** 姿態估計抽出關節座標與角度特徵後，我在交叉驗證下比較了 LSTM、ASFormer 和 heatmap 三種時序模型。ASFormer 的分數最高，但正式環境選的是 heatmap 方法：上線要顧的不只準確率，還有穩定度、推論成本和維護難度。

前端只和 Cloudflare Worker 溝通。Worker 負責登入、點數扣抵與 R2 的簽名上傳網址，再把分析工作丟進 Cloudflare Queues；推論跑在 Google Cloud Run 上的 FastAPI 服務，兩邊用 HMAC 簽章互相驗證。點數採帳本式記錄，付款通知的 webhook 可以重複接收而不會重複入帳。

## 成果

系統已交付給客戶。學員上傳影片後可以免費預覽，再用點數解鎖完整報告，內容包含三個關鍵時間點與四個關節角度的分析。
